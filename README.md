# servicebotwebsite

Website for Servicebot, built with Vue 3 (Options API), Vite, Vue Router and Pinia.

## Setup

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Configuration

Set the backend URL in a `.env` file:

```
VITE_API_BASE_URL=https://your-backend.example.com
```
